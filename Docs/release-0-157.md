# Выпуск 0.157 — 14.11.2026

Выпуск объединяет все четыре готовых исправления после 0.156: подписи захваток, прокрутку страницы, отклик выделения и перемещения, чувствительность колеса и тачпада. Сверка выполнена с актуальным `origin/main`. Других готовых изменений после 0.156 в публикуемой ветке нет.

В фильтрах захватка отображается как «Захватка 1. Ось 1», включая записи без геометрии с ручными назначениями. API плана возвращает подписи отдельно от контуров, значение фильтра остаётся ID захватки.

Страница захваток прокручивается до схемы и списка. Высота схемы зависит от окна. Процент масштаба и кнопка ⟲ «Вписать» находятся внутри схемы справа внизу. Вписывание не перечитывает модель. Колесо масштабирует вдвое медленнее, жест сведения и разведения пальцев использует самостоятельную чувствительность. Минимум обоих способов — 25% от исходного охвата, точка под курсором сохраняется.

При выделении меняется только подсветка нужных изделий. Существующие узлы схемы и толщина границ сохраняются, поле назначения захватки не сбрасывается. План перемещается при протяжке как за фон, так и за изделие. Координаты учитывают пропорции SVG, обновление выполняется по кадрам. Смещение менее 4 пикселей считается кликом. Рамка выделения видна при Shift и протяжке, захват указателя корректно освобождается при отмене или отпускании вне схемы. Добавление вершин контура также не пересоздаёт геометрию изделий.

В версии 0.157 нет новых миграций, обработок данных или зависимостей. Изменения API плана только добавляют поле метаданных. Корпоративная выкладка остаётся отдельным пользовательским пушем в GitLab.

Проверки перед выпуском:

- `scripts/test_capture_filter_labels.mjs` — восемь проверок подписей, в том числе отсутствие контура, номера или наименования и совместимость с прежним набором метаданных.
- `scripts/test_work_groups.py` — 18 сценариев групп и назначений на временной БД, включая API подписей ручных захваток без контура.
- `scripts/test_work_group_interactions.mjs` — настоящие события мыши на свежей обезличенной копии с 11 033 изделиями, замедление CPU в четыре раза. Выделение, неизменность геометрии и границ, сохранение поля назначения, перетаскивание с изделия и фона, отмена жеста, отпускание вне схемы, небольшое смещение при клике, рамка и рисование контура. В финальном проверенном прогоне отклик выделения составил 60 мс; это замер конкретного стенда, а не обещание для любого устройства.
- `scripts/test_work_group_viewport.mjs` — окна 1440×900, 2560×1440 и 1440×700, прокрутка, положение управления внутри схемы, колесо, события жеста тачпада, сохранение точки под курсором, минимум 25%, вписывание и отсутствие масштабирования страницы браузером. Выполнены `alignAudit` и `sizeAudit`, визуально проверены снимки 1440×900 и 2560×1440.
- Синтаксис изменённого JavaScript, структура и уникальность версий «Что нового», штатные проверки коммита.

Все перечисленные проверки повторно пройдены на итоговом коде перед публикацией.
