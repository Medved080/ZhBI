Как модули взаимодействуют

  • Реестр разделов (features.py) — источник, из которого берут перечень прав доступа, матрица прав, обучение и проверка эндпоинтов.
  • Реестр событий журнала (activity_actions.py) — единое соответствие «код действия → подпись и категория»; страж не пускает в коммит событие без подписи.
  • Описание схемы (db_schema_doc.py) — из него строятся экран «Состояние БД» и диаграмма схемы; расхождение с реальной базой подсвечивается красным.
  • Обработки релиза (release_tasks.py) — единая точка, через которую новая версия приводит накопленные данные в порядок.
  • Стражи — проверки при импорте и в git-хуке: необъявленные имена, события журнала, полнота обучения, целостность договоров, расширение прав.
