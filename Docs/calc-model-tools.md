# Подготовка частичных моделей калькулятора

В выпуск 0.147 по просьбе закоммитить всю накопленную работу включены исходники генераторов, импорта и проверок из соседних сессий. Это средства подготовки отдельных пакетов, а не обработка релиза. Их наличие не означает автоматическое добавление моделей на корпоративном сервере. Пакеты передаются отдельно штатным обменом калькулятора; базы, PDF, локальные резервные копии и временные результаты в Git не добавляются.

Генераторы `build_calc_quick_*` строят частичные бетонные тела ригелей, панелей и стен шахт. `build_calc_rebar_*` готовят отдельные дополнения подтверждённой арматуры/закладных с сохранением бетона. `build_calc_next_rigels_*` готовят следующую группу ригелей по собственным листам. Неразрешённые детали остаются явно неполными: частичная модель не заменяет проверку исходной спецификации и не подтверждает полноту армирования.

`import_calc_quick_models.py`, `import_calc_rebar_models.py`, `import_calc_next_rigels.py` проверяют пакеты перед применением; запись включается только явным `--write`. Проверяются источники, геометрия, согласованность метаданных и хеши защищённых старых моделей. Импорт не предназначен для перезаписи ручных расчётов или посторонних поставок. Перед применением проверяются справка `--help`, отчёт холостого прогона и резервная копия.

Независимые проверки: `verify_calc_quick_models.mjs`, `verify_calc_rebar_models.mjs`, `verify_calc_rebar_spacing.py`, `verify_calc_next_rigel_datums.py`. При выпуске 0.147 проверены синтаксис и неопределённые Python-имена всех включённых исходников. Существующие готовые пакеты дополнительно проверяются по координатам; новые генерация, импорт с записью и корпоративная передача в ходе выпуска кода не запускаются.
