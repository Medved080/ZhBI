# Факт поставки — общий отбор по одной дате

Запрос 17.11.2026: добавить фильтр «Факт поставки» с датой по аналогии с «Фактом монтажа».

В группе «Поставка» первым полем идёт «Факт поставки» — одна календарная дата. Доступен в модели, АРМ прораба и комплектовщика, V1/V2, 2D/3D/«3D лёгкий». Пустая дата отключает условие. Сброс группы и общий сброс снимают его; дата сохраняется в личном состоянии интерфейса. У комплектовщика группа содержит только фактическую дату, без модельных плановых и прогнозных отборов.

Источник — существующее `actual_delivery_date`: последний переход в `delivered`, сохраняемый при последующем монтаже и приёмке. Полный откат в `planned` или удаление записи поставки очищают дату по существующим правилам истории. Фильтр сравнивает первые десять символов с выбранным календарным днём, без пересчёта часового пояса и привязки к ночной смене. Изделия без даты не проходят выбранный день. Дополнительного ограничения текущего статуса нет: поставленное изделие остаётся поставленным после монтажа.

Отбор пересекается с другими фильтрами, включая факт монтажа. Изменения даты из карточки, истории и `/changes` применяются общим механизмом delta без перезагрузки страницы. У комплектовщика учитывается в счётчиках и отборе контрактов; документальное количество контрактации по фактической дате не вычисляется, поскольку позиция контракта такой даты не имеет.

Реализация: `app/static/app.js`, `embed-bridge.js`, `v2/workspace.js`. Существующие ответы API уже содержат поле поставки. Новых полей БД, миграций, обработок и зависимостей нет. Пользовательская справка дополнена, редакция `2026-11-17.5`.

Проверка: `scripts/delivery_filter_fixture.py 8072` — отдельный синтетический стенд; `scripts/test_delivery_filter_ui.mjs` — V1/V2 × три рабочих места × три вида, поставка с последующим монтажом и приёмкой, отсутствие даты после полного отката, полночь, пересечение отборов, очистка/сброс/восстановление состояния, изменение истории через API и опрос изменений, аудит выравнивания и скриншоты 1440×900/2560×1440. Регрессия монтажа: `scripts/test_montage_filter.py`, `scripts/test_montage_filter_ui.mjs`.
