# V2: дизайн-основа полного интерфейса

## Источник дизайна
- Утверждённый прототип «Пользователи и доступ» (`#ua-concept`) в репозитории **отсутствует**: упомянут только в комментарии `app/static/v2/styles.css`; сам макет и переданные дизайн-спецификации в дереве не найдены (`Docs/design/chess-flat/` — это дизайн плоской шахматки, не прототип пользователей).
- Поэтому основа полного интерфейса — **согласованные компоненты и токены V2**, уже применённые в трёх перенесённых разделах (`app/static/v2/styles.css`). Точное совпадение с прототипом **не заявляется**; если макет найдётся — сверять токены ниже.

## Токены (`:root` в `styles.css`, светлая/тёмная схемы через `light-dark()`)
| Токен | Назначение |
| --- | --- |
| `--bg`, `--surface` | фон страницы / фон боковой навигации, шапок таблиц, плашек |
| `--ink`, `--muted` | основной / второстепенный текст |
| `--line` | границы и разделители |
| `--accent`, `--accent-ink`, `--sel` | акцент (главные действия), текст на акценте, выделение |
| `--good`, `--bad` | успех / ошибка и опасное действие |
Типографика: системный шрифт 14/1.45; заголовки экрана 22/600 (`h2`), блока 15–18/600; подписи и метки не мельче 12px (проверяется сценариями VIS).

## Компоненты (классы `v2-*`)
- Кнопки: `.v2-btn` (обычная), `.v2-primary` (главное действие), `.v2-danger` (необратимое; красная), disabled — приглушённая, без курсора-руки.
- Оболочка: `.v2-head` (шапка: название, выбор объекта, пользователь, «← Текущий интерфейс»), `.v2-shellnav` (левая навигация: поиск, группы со сворачиванием, пометки «V1»/«чт.»/«прав.»), `.v2-page` (область экрана).
- Экран: `.v2-screen` (хлебные крошки → заголовок + статус-плашка → пояснение → `.v2-callout` → содержимое); плашка сообщает, работает ли экран в V2 и куда идти за остальным.
- Таблицы: `.v2-read-tbl` (просмотр, заголовки закреплены, горизонтальная прокрутка внутри области), `.v2-table` (карточные списки трёх перенесённых разделов).
- Карточки/плитки: `.v2-card`, `.v2-tile`; чипы: `.v2-chip` (`-ok` зелёный, `-warn` приглушённый), уровни аналитики `.v2-sev-*`.
- Диалоги: общий `dialogs.js` (`showConfirmDialog`, `showInfoDialog`, `showUnsavedDialog`) — одна ловушка фокуса, Escape = отмена.
- Состояния: загрузка («Загрузка…», `role=status`), ошибка (`.v2-callout-bad`, текст сервера + «Повторить»), пусто (явная фраза, отличная от «ничего не найдено по запросу»), «выберите объект».
- Каркас неперенесённого экрана: `.v2-wire*` — пунктирная рамка, неактивные поля, подпись источника структуры; над ним прямым текстом «работает только в текущем интерфейсе».

## Расположение действий
Главное действие — `.v2-primary` справа в строке ввода/подвале формы; опасное — отдельная красная кнопка в строке записи с подтверждением через общий диалог; переход в V1 — крупная кнопка в плашке экрана.

## Проверка
Размеры 1920×1080, 1920×900, 1366×768 при масштабе 100% (без `zoom`/`transform: scale`): сценарии `VIS-*` (нет горизонтальной прокрутки страницы, каркас и подвал в пределах экрана, длинное — прокрутка внутри области, текст ≥12px) и `A11Y-*` (доступные имена, tabindex, aria-live, порядок заголовков). Сцены оболочки: `shell-home`, `shell-screen-form`, `shell-screen-report`, `read-table`, `read-tabs`, `read-record`, `dict-edit`.
