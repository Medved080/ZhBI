4. Оболочка V2 (`main.js`, `registry.js`, `screen-view.js`): левая навигация, начальная страница, контекст «Объект» (права и ссылки в V1 — по объекту; на сервер не пишется; смена объекта проходит сторож несохранённого), маршруты `#/экран`, каркасы форм V1 с переходом в V1.
5. Чтение (`read-screen.js`, `reports.js`, `api.readPost`): 24 экрана + отчёты; правка: `dict-edit.js` (СМУ, физлица), `setting-edit.js` (порог опоздания), `color-edit.js` (цвета зон и статусов), `prefix-edit.js` (префиксы марок). ## Риски и оговорки
- Ограничение инструмента браузера: Enter/Backspace на полях ввода не срабатывают нативно (реальные ввод текста и клики работают); `ctrl+a` не выделяет всё. Значения `<input type=color>` выставлялись программно.
- Эмуляция viewport в панели: после `reload()` скриншот может быть масштабирован неверно — помогает повторная навигация (`navigate`) и `resize_window`.
- На настоящем backend проверялись только права администратора; права остальных ролей — только на стенде (имитация).
- Данные копии БД после живых проверок восстановлены: `smu_catalog` = 6, `mark_type_prefixes` = 12, порог опоздания объекта 2 = 0, цвета кранов объекта 2 и статус `planned` — исходные. В журнале действий остались события проверок; последний выбранный объект пользователя QA-Overnight Test — «Объект-2» (V1-переход по глубокой ссылке записал его).
