3. V1: `applyStartupDeepLink()` — `?ws=`, `?view=`, `?open=menu&item=<id>` (виден роли, не «опасный»).
4. Оболочка V2 (`main.js`, `registry.js`, `screen-view.js`): левая навигация по 9 группам с поиском, начальная страница, контекст «Объект» (права и ссылки в V1 — по объекту; на сервер выбор НЕ пишется), маршруты `#/экран`, каркасы форм V1 с переходом в V1.
