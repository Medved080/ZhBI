# Аудит «рабочие места и отчёты»: V1 → V2 по сценариям (2026-09-22)

Ветка `feature/v2-audit-work` (worktree `/Users/max/zhbi-w-audit-work`), порты проверок 8370–8379. Метод: для каждого экрана —
что человек делает в V1 (разметка и обработчики `app/static/app.js`/`index.html`), как то же в V2, тот же ли результат; категория
