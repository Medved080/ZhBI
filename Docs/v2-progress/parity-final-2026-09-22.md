# Итог: «V2 до полного соответствия V1» — сводный отчёт по четырём параллельным областям (2026-09-22)

Сводит `map.md`, `access.md`, `charts.md`, `graphics.md` в одну таблицу по требованию задания: не
объявлять перенос завершённым по наличию API/кнопок/разрешений шлюза, а сравнивать сценарий V1 →
сценарий V2 → тот же ли результат. Публикация кода — `Docs/v2-workspaces.md` §0 (публикации №7–9).

## 1. Метод

Для каждого пункта задания (карта, графики отчётов, графические операции, вход под пользователем) —
настоящий backend (копия обезличенной БД, `scripts/real_auth_server.py`), настоящий вход, настоящий
браузер (`scripts/cdp.mjs`, headless Chrome, реальные события мыши — `Input.dispatchMouseEvent`), а
не вызовы внутренних JS-функций. Каждая ветка проверена дважды: своим исполнителем и НЕЗАВИСИМО ещё
раз при слиянии (см. эту сессию: 41+38+69+38 проверок веток, затем 251/251/38/38/69 при интеграции —
backend 7/7, модель 189/189, оболочка 87/87 повторены на каждой из трёх публикаций).
