## Найденные дефекты (не связаны с UI)

1. **Восстановление резервной копии не работало** (`app/backups.py`): копия снята с базы в режиме WAL, а открывалась `file:…?mode=ro` — SQLite не может открыть такую копию без файлов `-wal/-shm`
   («unable to open database file»): статистика копий была пуста, `POST /admin/backups/{name}/restore` отвечал 500. Исправлено (`immutable=1`), проверено восстановлением. **Тот же приём `mode=ro` стоит в
   `app/db_transfer.py` (4 места) — область «обмен»: вероятно, тот же дефект при переносе базы снимком; не менялось, передать исполнителю/интегратору.**
2. Дубль СМУ/физлица другим регистром кириллицы проходил (`COLLATE NOCASE` не сворачивает кириллицу).
3. Вложение можно было положить несуществующему объекту (запись и файл без хозяина).
4. Кнопка «Задать пароль» V2 при пустом поле отправляла пустой пароль = блокировку входа человека (исправлено: пустой не отправляется, блокировка — отдельная кнопка с подтверждением).
5. Выбор раздела в тесте обучения терялся при перерисовке до чтения значения (найдено проверкой, исправлено).
6. **Файлы вложений стирались до commit**: при откате удаления объекта/проекта записи вложений возвращались, а файлы были уже удалены (410 при скачивании). Исправлено: файлы стираются
   после commit (`attachments.flush_pending_unlinks`), при откате не трогаются (проверено триггером-сбоем на копии).
7. Экран «Сеансы» в V2 был доступен только при праве «Пользователи: изменение» (склейка двух пунктов V1) — обычный пользователь не видел «Мои сеансы»; добавлено `menuFeatures` в реестр.
   Пункты «Очистить историю статусов» и «Памятка администратора» показывались всем — теперь по праву.

## Что остаётся в V1 (с причиной)

* **Адресный классификатор КЛАДР** — многошаговая фоновая загрузка (скачать/распаковать архив на сервере, выбрать регионы, минуты работы с опросом состояния); без файлов классификатора и доступа к
  nalog.gov.ru в тестовой среде проверить её нельзя. Просмотр состояния — в V2.
* **Удаление непустых проектов/объектов** — правило V1 (за объектом стоят изделия и история): здесь сохранено, план показывает, что мешает.
* **«Зайти под пользователем»** — V2 создаёт отладочный сеанс, а вкладка открывается в V1: только он подставляет токен во ВСЕ запросы (рабочие места V2 — вложенные кадры со своими запросами).
* Редактор ячеек «Права пользователей» V1 заменён операциями «выдать/снять/системная роль» с предпросмотром (тот же итоговый результат за 1–2 операции).
* Успешная привязка/поиск в НАСТОЯЩЕМ домене не проверялись (контроллера домена нет): проверены недоступный сервер, валидация, стенд с имитацией.
