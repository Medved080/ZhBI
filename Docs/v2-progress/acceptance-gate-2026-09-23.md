# V2 — проверка оставшихся пометок «только V1» (2026-09-23)

Цель — не считать число зелёных экранов доказательством полноты, а сверять конкретное действие V1 с действием V2 и его результатом. Инвентаризатор V1 (`scripts/inventory_v1_ui.py`, HTML-дерево + токенизатор JS с самопроверкой) на текущем коде: 71 пункт меню, 83 модальных экрана, 38 кнопок вне меню/модалок; разбор и текст разметки совпали по 1185 `id`, разбор и текст JS — по 1918 `getElementById`. Это инвентарь, не утверждение, что все действия прошли живую приёмку.

| Действие/пометка | Фактическое состояние | Проверка/решение |
| --- | --- | --- |
| Привязать контракт одному изделию | Уже было в V2: карточка схемы → «Контрактация», безопасный `POST /element-ops/contract` | `scripts/verify_element_ops.py` S11, прежняя проверка браузером; устаревшая подсказка справочника исправлена |
| Плановая дата группе изделий | Уже была в V2: одна дата пачке и отдельные даты по строкам | `scripts/verify_element_rows.py`, браузерный `verify_lines_ui.mjs`; устаревшая пометка исправлена |
| Сменить контракт группе, не меняя статус | До этой проверки отсутствовало: форма V2 исключала строки с уже выбранным статусом, сервер возвращал 409 | Исправлено `c913ac7`: неизменённые строки не отправляются, прежний статус + новый контракт допускается; полный HTTP-набор без нарушений, браузер 14/14, V1-маршрут остался прежним |
| Управлять файлом карты / переключать источник | Уже было в V2: «Карта: подложка и источник»; на карте отдельный выбор «С сервера» / «Из интернета» | Сверено по `admin-service.js`, `map-screen.js`, `map.js` и ранее записанным проверкам `verify_admin_backend.py`/`verify_admin_ui.mjs`; в этот день файл карты и внешний источник не переключались |
| «Динамика» → правка заметок на дату | Уже было в V2: кнопка «✎ Изменить» и `v2.notesPrefill` | Сверено по `reports-work.js` и `card-edit.js`; реестр ссылался на старый ключ и ошибочно отрицал кнопку |
| Сеансовые «Подписи» / «Даты» | Уже было во вкладке «Вид» рабочего места V2 | Сверено по `workspace.js`; старая пометка реестра исправлена |
| «Что нового» → обработки обновления | Уже было в V2 для администратора через `admin:changelog` | Сверено по `main.js`, `admin-screens.js`, `admin-service.js`; старая пометка реестра исправлена |
| PDF-схема по фильтру текущей схемы | Нет ни в V1, ни в V2: `GET /export.pdf` принимает только чертёж и дату | Уточнена пометка реестра; это не дефект паритета. XLS поддерживает снимок отбора |

Не закрыто этим проходом: сквозная повторная приёмка всех ролей и всех 76 записей реестра на одном финальном коммите; она нужна перед снятием общей экспериментальной плашки. У отчёта «График контрактации» выгрузок XLSX/PDF нет и в V1 (кнопки V1 отвечают 404) — это отдельная новая функция, решение о ней не принято. Вопрос отправки адреса страницы наружу при онлайн-карте не менялся: для изменения политики нужен выбор пользователя.
