Поддержаны вертикальные, повёрнутые и совпадающие профили. Невместившаяся марка вызывает понятную 422 вместо уменьшения кегля, пропуска или свободной выноски на поля.

Дневной Excel вкладки «Факт» начинается листом «Реестр СНЗ» по образцу пользователя: №, дата начала, смена, бригада, прораб, количество плана/факта и итог по документам.
