# Факт монтажа — общий отбор по одной дате

Запрос 10.11.2026: во всех рабочих местах ЖБИ и видах схемы показывать смонтированные изделия за конкретную дату, с тем же определением факта, что в отчёте о статусе монтажа. Пользователь выбрал одно поле, не диапазон.

В разделе «СМР» первым идёт «Факт монтажа»: календарная дата факта, не план СНЗ и не дата начала ночной смены. Пустое поле отключает условие; группа «СМР» и общий сброс снимают его. Другие отборы продолжают пересекаться. Дата сохраняется в личном состоянии схемы для рабочего места/объекта, как прочие фильтры. Доступны модель, прораб и комплектовщик в V1/V2, 2D/3D/лёгком 3D. У комплектовщика добавлена общая группа СМР с этим полем; документальное количество контрактации за день не вычисляется, поскольку у позиции контракта нет даты монтажа.

Источник истины — `app/status_facts.last_run_day_sql`, используемый отчётами и актуализациями: только текущие `installed`/`accepted`, начало последней непрерывной серии этих статусов. Приёмка не сдвигает монтаж; откат исключает изделие; повторный монтаж относится к новому дню. Изделие без подтверждённой даты не проходит выбранный день.

Первичная схема уже получает дату в `forecast_smr_end_date` с `forecast_smr_is_fact`. Ответы карточки, смены статуса, операций V2 и `/changes` теперь содержат вычисляемое `actual_installation_date`. Явный `null` при откате заменяет прежний снимок. Общий предикат применяется к обычным фильтрам и срезам комплектовщика, в том числе подсветке неприкреплённых изделий. Изменение даты в истории при том же статусе меняет отбор при очередном опросе. Новых зависимостей, схемы БД, миграции или обработки релиза нет; существующая история не переписывается.

Стенд содержит только синтетические данные и никогда не обращается к порту 8000.
