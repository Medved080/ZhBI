# Выпуск 0.155 — 13.11.2026

Выпуск подготовлен по команде пользователя «пушим». Сверены изменения после последней описанной версии 0.154. В выпуск входит функциональный коммит `8487a5e2` с привязкой фасадных панелей к физическому каркасу. Версии 0.153 и 0.154 описывают предшествующие изменения СНЗ и смены статуса.

Внутренняя грань каждого фасада совмещается с крайней наружной гранью колонн и ригелей в пределах развёртки. Остаётся одна плоскость на фасад. Привязка вдоль прямых фасадов уточняется по физическим колоннам. Отступ 0 мм означает примыкание к каркасу. Анализ хранит снимок каркаса, применение проверяет его повторно и внутри транзакции.

Исправление проверено на копии рабочей модели, затем применено к пяти развёрткам объекта «Москвич → Промышленный корпус» на локальном сервере 8000. Обновлены 1457 панелей. Сохранены GUID, статусы, контракты и история. Перед записью создана штатная резервная копия. Итоговая геометрия рабочей БД совпала с проверочной копией. Пять событий исправления присутствуют в журнале.

Проверка геометрии использует контуры рабочей модели и высоты из её штатного 3D-расчёта. Устранены 555 пересечений панелей с колоннами и ригелями. Критерий объёмного пересечения включает глубину и перекрытие по высоте больше 1 мм. В габаритной модели остаются пересечения самих панелей, включая угловые изделия. Для уточнения их контуров нужен узел угловых изделий.

Регрессия включает 34 серверных сценария пакета `feature_shaft_panels/tests` с пятью исходными DWG и 84 проверки шлюза `scripts/v2_tests/exchange-gate.selftest.mjs`. Проверено примыкание Пс-3034 в 3D на копии. При выпуске повторяются серверные проверки, проверки шлюза, структура changelog и штатные проверки коммита.

На корпоративном проде после обновления требуется повторно загрузить пять DWG в тот же объект с толщиной 440 мм и отступом от каркаса 0 мм. Существующие фасады получают исправленную привязку при повторном импорте. Публикация кода в GitHub и корпоративный CI/CD выполняются отдельными шагами, GitLab запускается пользовательскими пушами main в develop и production.
