# Калькулятор: обновление, свойства и истечение сеанса — 12.11.2026

Причины обращения: самостоятельная страница `/calc/` не проверяла `/app-build`, в то время как V1/V2 уже опрашивали его. При истёкшей сессии проверка V2 получала 401 и молча пропускала ответ. Калькулятор показывал ошибку загрузки отдельной модели, оставляя остальной интерфейс доступным. Независимый дефект свойств: длинное описание распознанных данных в `dd` с `white-space:nowrap` растягивало автоматическую колонку и выталкивало числовые значения за границы панели.

Калькулятор теперь запоминает первый корректный отпечаток сборки и сравнивает его каждые 15 секунд, при возвращении видимости и фокуса. Проверка без кеша; изменение кода при том же номере версии тоже показывает постоянную полосу. При неизменном отпечатке перезапуск сервера уведомления не вызывает. Автоматической перезагрузки нет. Кнопка обновления ждёт сохранения расчёта; несохранённые нормы и открытая форма изделия требуют сначала завершить редактирование, ошибки сохранения блокируют перезагрузку. Внутри V2 обновляется вся оболочка, чтобы заново получить HTML кадра. Для уже открытых старых страниц требуется однократное ручное обновление.

Общий `app/static/session-notice.js` подключён в V1, V2 и калькуляторе. После успешного подтверждения входа ответ 401 проверяется отдельным `/me`; только подтверждённая потеря общего сеанса вызывает блокирующее окно. Начальный вход, неверный пароль, 403 и временные сетевые/серверные ошибки не вызывают ложного сообщения об истечении. Ответ исходного запроса сохраняется для вызывающего кода. Повторные отказы не создают новые окна; кадр калькулятора использует уведомление родительской оболочки. «Войти снова» перезагружает верхнюю страницу, учитывая штатный `beforeunload`. Ввод калькулятора сохраняется в существующих локальных черновиках; несохранённые нормы/открытая форма тоже защищены предупреждением перед уходом. Автоматического повторения изменяющих запросов по факту показа уведомления нет.

Панель проектных свойств получила ограниченные колонки с переносом значений. Длинные описания и состав закладных занимают отдельные строки полной ширины; объём, масса и коэффициент армирования остаются внутри панели. Неизвестные проектные значения не вычисляются из габаритов и не подменяются: дефект касался отображения.

Проверка — `scripts/test_calc_updates_session_ui.mjs`: временная обезличенная база и отдельная новая база калькулятора, длинные синтетические описания, 1440×900 и 2560×1440, геометрия границ и аудит формы уведомления, сохранение перед обновлением и отказ сохранения, обновление V2 с кадром, реальное удаление тестовой cookie-сессии для V1/калькулятора/V2, повторные 401, отказ неверного пароля и отсутствие ложной тревоги при доступном `/me` или 503. Справка 2026-11-12.3. Схема и прикладные данные не меняются; запись «Что нового» предлагается отдельно, новый пуш — по команде пользователя.

Локальная проверка 8000: процесс 96781 предыдущего выпуска заменён 14609; `/health`, `/v2`, `/calc/` отвечают 200, десять изменённых ресурсов совпадают с файлами, `/app-build` и `/calc/api/auth/me` без входа отвечают 401. Тестовые стенды остановлены. Новые браузерные сценарии, регрессия норм, клиентские номера запросов, 7 тестов справки и покрытие 91/91 прошли; снимки просмотрены на обеих размерностях. Корпоративного выпуска этой доработки не было.
