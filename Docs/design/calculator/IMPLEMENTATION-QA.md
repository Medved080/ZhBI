# Проверка реализации калькулятора · 05.10.2026

Изменения внесены в рабочие файлы `app/calc/web/`. Отдельные `workspace-ui.js` и `workspace.css` подключены в HTML и зарегистрированы в существующем списке выдаваемых файлов. Рабочий сервер на порту 8000 возвращает оба файла с HTTP 200.

## Что реализовано

- Старт с карточки изделия; восстановление последнего изделия, вкладки, поиска, альбома, группировки, раскрытых групп, прокрутки и режима сравнения. Прямая ссылка на изделие открывает его калькуляцию.
- Верхняя навигация «Изделия / Готовность / Цены и нормы / Отчёты / Сервис».
- Каталог с независимой прокруткой. Статистика 3D из боковой панели удалена; данные доступны в готовности, результаты обработки — в сервисном меню.
- Массовый выбор включается отдельной кнопкой. XLSX открытого изделия находится в карточке, выбранных — внизу каталога, всего проекта — в отчёте.
- Четыре основные вкладки карточки; вложенные разделы документов и проверки; технология и история в «Ещё». Клавиатурное переключение основных вкладок.
- Пять видимых колонок калькуляции; расчёт сервиса раскрывается переключателем сравнения. Сохранены корректировки количества, цены и суммы, точность денег и серверное автосохранение. Ручные поля выделяются цветом.
- Изменение параметров доступно прямо из калькуляции. Сброс ручных правок требует подтверждения с названием изделия.
- Настройки разделены на цены, нормы и начисления. Подробности готовности свёрнуты в раскрываемые разделы.
- На мобильном экране каталог открывается отдельной областью выбора; таблица прокручивается внутри своего контейнера.

## Проверено

Браузерные проверки выполнялись через CUA на изолированном сервере `127.0.0.1:18801`, с временными базами и копиями JSON-каталогов в `/private/tmp/zhbi-ui-test-20261005`. Рабочие расчёты не редактировались.

- Полный каталог: 1008 изделий. Поиск `1Р2` находит `1Р2` и `1Р2.1`; очистка и возврат к активному изделию работают.
- 1366×768: область списка 510 px без массового выбора, 478 px с выбором; строка изделия 32 px. 1920×1080: список 790 px с массовым выбором. 390×844: мобильный список 554 px с массовым выбором. Горизонтального переполнения страницы нет; широкая таблица прокручивается внутри контейнера.
- Ручная сумма бетона `40000,12` выделяется цветом, влияет на зависимые статьи и итог и сохраняется после перезагрузки. Сравнение и массовый выбор также восстанавливаются.
- XLSX открытого изделия и отдельно выбранного другого изделия: интерфейс сообщает успешное формирование книги с одним листом. Событие загрузки встроенного браузера не было получено через `waitForEvent`; состав скачанных файлов отдельно не исследован.
- Переходы «Готовность → Цены и нормы → Отчёты → Изделия», подразделы «Нормы / Начисления», вкладки «Документы / Проверка» работают.
- Отмена подтверждения сброса оставляет ручную сумму. Найденная при первой проверке ошибка обращения к диалогу вне корневого контейнера исправлена и повторно проверена.
- `node --check` для всех пяти изменённых JS-модулей; синтаксический разбор Python; уникальность HTML ID; `git diff --check` — успешно.
- Формулы `rowData`, `getValue`, `calculate` сравнивались с копией до правок: не изменены, включая приоритет ручной суммы.
- `verify_calc_prices.py` с полным каталогом: 0 провалов. Проверены массовый пересчёт цен, ручные правки, версии и конфликт 409, отсутствие отрицательных строк на 1008 изделиях.

Снимок результата: `implemented-desktop.jpg`. Скриншот снят с тестовой базы, поэтому названия и цены начальных двух изделий — тестовые данные.
