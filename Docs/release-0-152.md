# Выпуск 0.152 — 12.11.2026

По команде пользователя «пушим». Проверены коммиты после последней описанной версии 0.151. В выпуск входит функциональный коммит `744dcfe6` с загрузкой фасадных панелей. Других неописанных функциональных коммитов в main на момент подготовки выпуска нет.

В «Что нового» описана форма «Панели фасадов и шахт», загрузка пяти видов DWG Tekla СМ1, тип «Панель» с подтипом «фасадная», размеры и отметки из развёрток, толщина 440 мм по разрезу 2–2 и настраиваемый отступ. Развёртки сохраняются отдельными областями импорта, повторная загрузка сохраняет идентификаторы и статусы.

Проверены 1457 панелей и 979 марок, повторная загрузка, обновление толщины с сохранением идентификаторов, исходные изделия объекта и высоты всех панелей в общей 3D-модели. Проверены сечение 100+150+190 мм, внешние ключи, alignAudit/sizeAudit и снимки формы на 1440×900 и 2560×1440. Для снимка сборной модели отключены внешние FBX-фасады и благоустройство.
