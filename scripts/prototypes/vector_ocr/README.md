# Прототип: чтение векторных листов КЖИ без нейросети (2026-10-04)

Листы КЖИ — распечатка из CAD в PDF без текстового слоя: буквы и цифры — наборы мелких штрихов. Прототип собирает штрихи в символы и читает
числа, текст и спецификацию правилами, а каждый размер проверяет по геометрии. Выводы, цифры и оценка трудоёмкости — `Docs/calc-vector-ocr.md`.

Зависимости: `pypdfium2`, `Pillow`, `numpy` (Python 3.12: `.venv312/bin/python`). Исходные PDF — `data/calc/assets/sources/docNN.pdf` (только чтение).

| Модуль | Что делает |
| --- | --- |
| `vector_ocr.py` | штрихи страницы в экранных координатах (учёт `/Rotate`) → символы-цифры по эталонам `digit_protos.json` (+ `digit_protos_alt.json`, вторая гарнитура) → числа → проверка размера по засечкам и масштабу вида |
| `analyze.py` | калибровка масштаба печати k (лист мог быть уменьшен с A2), нулевая модель (доля случайных совпадений), метрика полноты `geometry_dims` |
| `glyphs.py`, `textcells.py` | текст: строки, расшатка курсива, ячейки символов (склейка фрагментов «к», «н», «й»), растр в системе строки |
| `train_font.py`, `font_protos.json` | эталоны букв: самообучение по словарю типовых строк (число ячеек = число символов + сходство); в git только растры символов |
| `lexicon.py` | привязка слов к словарю с дешёвой заменой похожих начертаний, нормализация шифра документа |
| `tables.py` | рамки таблиц по линиям, текст по рамкам, разбор спецификации по ролям столбцов |
| `models_ref.py`, `compare_models.py` | эталонные цифры из каталога моделей поставщика и сравнение с прочитанным |
| `evaluate.py` | сводная оценка на списке листов `doc:page` |

```bash
.venv312/bin/python scripts/prototypes/vector_ocr/vector_ocr.py data/calc/assets/sources/doc01.pdf 270   # размеры листа
.venv312/bin/python scripts/prototypes/vector_ocr/evaluate.py 1:270 14:7 6:59                           # размеры + спецификация
.venv312/bin/python scripts/prototypes/vector_ocr/compare_models.py 1:229 4:76                          # сравнение с моделями поставщика
```

Файлы `*_last.json` (результаты прогонов с марками и числами заказчика) в git не идут (`.gitignore`).
