# Прототип: чтение векторного листа КЖИ без нейросети (2026-10-04)

`python scripts/prototypes/vector_ocr/vector_ocr.py <pdf> <физическая страница>` — разбор страницы: штрихи PDF → символы (связные штрихи)
→ цифры по эталонам шрифта CAD (`digit_protos.json`, любой поворот 0/90/270°) → числа → проверка каждого размера по геометрии
(засечки размерной линии, интервал в pt против стандартного масштаба вида, допуск ±0,8 pt). Нейросеть не используется.

Эталоны цифр сняты с листа doc01 стр. 270 (шрифт альбомов КЖИ); буквы и знаки не распознаются. Прототип проверен только на этом листе —
на других листах/альбомах не пробовался. Зависимости: pypdfium2, Pillow, numpy.
