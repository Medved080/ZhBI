Проекты

Проект — группа объектов, как правило соседних зданий одной площадки. Собственных данных у проекта нет, кроме реквизитов: все свойства, справочники и контракты живут внутри объекта. Сроки СМР не задаются, а сводятся из сроков подчинённых объектов — поэтому не могут с ними разойтись.

Объекты

Объект — здание или стройплощадка. Элементы принадлежат объекту, а не файлу чертежа: новая версия чертежа обновляет их, сохраняя статусы и историю.

Чертёж загружается отдельно — «Обмен данными → Загрузить чертёж».

Элементы

Щёлкните строку, чтобы увидеть статусы элемента. Двойной щелчок по строке открывает форму элемента с правкой полей и истории.

Ничего не изменит — только покажет расхождения.

Выгрузите снимок реквизитов всех элементов всех объектов, поправьте в Excel и загрузите обратно. Система покажет расхождения — применится только то, что вы отметите флажками. История статусов в этот файл не входит — для неё переключитесь в режим «История статусов».

Лист «Статусы» — строка на элемент, колонка на каждый статус, в ячейке дата. Пустая ячейка означает «не трогать», а не «удалить запись». Порядок статусов проверяется: если дата более позднего статуса раньше предыдущего, строка отклоняется и не грузится. Другие статусы система сама не меняет — применяется ровно то, что вы отметили.

Импорт истории статусов из XLS

Запись «Запланирован», созданную импортом чертежа, импорт сам сдвинет раньше самого раннего события элемента — иначе проставленная задним числом дата поставки/монтажа оказалась бы раньше неё и статус откатился бы в «Запланирован».

Восстановление статусов из выгрузки

Для случая, когда история статусов элементов была потеряна (например, после аварийной пересборки БД) — принимает файл выгрузки "Статус на дату" (Действия → Обмен данными → Экспорт в XLS) или "История статусов". Для КАЖДОГО элемента, найденного в файле, история пересоздаётся заново по нему (режим "Заменить") — обычное "Дополнить" здесь не сработает: у только что пересозданных импортом чертежа элементов уже есть свежая запись "Запланирован" с сегодняшней датой, она новее восстанавливаемых дат и "победит" как последняя.

Отчёт «Динамика» на выбранную дату показывает последнюю редакцию, дата которой не позже отчётной. Обновлять каждый день не нужно — достаточно вносить изменения тогда, когда они появились.

Резервные копии базы данных

Копия содержит всю базу целиком: элементы и историю их статусов, пользователей, контрагентов, договоры, спецификации и контракты с позициями, зоны, все справочники, настройки и журнал действий. Выборочного экспорта нет — теряться нечему. Копии хранятся на диске сервера, в папке data/backups/ рядом с самой базой. Восстановление всегда начинается с автоматической служебной копии текущего состояния — если выбрана не та точка, вернуться будет куда.
